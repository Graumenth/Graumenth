# Can İşgüder

Airline pilot. I write software between flights, and most of it exists
because I wanted it to exist, not because anyone asked for it.

A lot of my time goes into tools for pilots. I built a logbook that pulls
flight reports straight out of my inbox so I never type a flight in by
hand, a study app for instrument rating and company manuals, and a small
utility that does runway wind math so I don't have to. I use all of them
on the job, which keeps them honest.

The big side project is an MMO in Unity: dedicated server, PostgreSQL,
Redis, and netcode that beats me roughly every other week. It is also how
I actually learned backend architecture, mostly by getting it wrong the
first time.

Lately I've been going down the stack: C, syscalls, interrupts, paging,
the whole kernel curriculum. The long-term plan is writing my own
operating system. Yes, everyone says that. We'll see.

There's also a fantasy novel in Turkish, in progress. "I'll finish it
later" is a valid life strategy.

If you want to build something together, make it backend. Please, no
frontend. I'm begging you.
